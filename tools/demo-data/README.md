# 시연 데이터 도구

현재 설치된 디버그 앱의 목표·회고·잎 보상·도착 한 줄 안내·지도 기능을 빠르게 확인할 수 있는 시연 보조 스크립트입니다.

## 1. 도착 후 회고 시연 (`Load-ArrivalDemo.ps1`)

PowerShell에서 `Load-ArrivalDemo.ps1` 실행 후 앱의 **주행 회고**를 누릅니다.

1. 샘플 급감속 후보 2개(1분 38초 48→18km/h, 3분 35초 35→10km/h)의 상황을 확인합니다.
2. ‘시연 · 신호가 바뀌기 전에 미리 속도 줄이기’ 목표에 **잘됐어요** 또는 **어려웠어요**로 답합니다.
3. 두 응답 모두 잎 1장을 얻고, 반복 탭·화면 재진입으로 중복 지급되지 않는 것을 확인합니다.
4. **정원 기록**에서 완료한 샘플 목표 2건과 기존 이력을 확인합니다.
5. 다음 목표를 선택·저장해 씨앗을 심습니다.

## 2. 출발부터 이어서 시연 (`Load-DepartureDemo.ps1`)

`Load-DepartureDemo.ps1` 실행 → 저장된 연습 목표 확인 → GPS 시뮬레이션 실행 → 콘솔 D단·가속 → 브레이크·P단 → 주차 확정 후 한 줄 음성 → 회고 응답·잎 보상 순서로 확인합니다.

## 3. 원본 데이터 복원 (`Restore-OriginalData.ps1`)

- 시연 데이터 적용 전 기존 앱 데이터를 `%USERPROFILE%/Downloads/DRIVE_MATE_demo_data_backups`에 자동 백업합니다.
- `Restore-OriginalData.ps1`을 실행하면 첫 시연 데이터 로드 직전 상태로 복원됩니다.
