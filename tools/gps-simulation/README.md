# 콘솔 속도 → GPS 주행 시뮬레이션

PC에서 실행하는 시연 전용 도구입니다. 앱은 수신한 GPS 위치를 표시합니다.

1. 에뮬레이터와 DRIVE_MATE를 실행하고 주차 상태에서 목적지를 정합니다.
2. PowerShell에서 `Start-GpsSimulation.ps1`을 실행합니다.
3. [조작 콘솔](http://127.0.0.1:18088/)에서 D단을 선택하고 가속하면 차속에 맞춰 GPS가 OSRM 도로 경로를 따라 이동합니다.
4. 브레이크로 속도를 줄이고 P단을 선택하면 이동이 멈추고 앱이 주행을 마칩니다.
5. 시연이 끝나면 `Stop-GpsSimulation.ps1`을 실행합니다.

목적지 변경 시 새 경로를 읽습니다. 목적지 해제·기록 중지 상태에서는 GPS를 이동시키지 않습니다. 콘솔이 비활성화되거나 P/N단이면 위치를 유지합니다. R단은 진행했던 경로를 되짚습니다. 경로 끝에서는 GPS가 멈추므로 콘솔에서 P단을 선택해 주행을 종료해 주세요.

에뮬레이터 GPS만 모의 입력합니다. 앱 저장값이나 차량 속도·기어를 직접 덮어쓰지 않습니다. 실제 내비게이션이나 실차용 기능이 아닙니다. 콘솔을 브라우저로 열어 활성 상태로 두어야 합니다.

Python 3 표준 라이브러리, 현재 사용자 Android SDK/ADB, emulator-5554, Android 사용자 10, 디버그 앱을 사용합니다. 테스트: `python -m unittest test_console_gps_sim.py`. 상태 로그: `%TEMP%/drivemate-console-gps.log`.
